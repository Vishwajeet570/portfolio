# Vishwajeet Singh Rathore — Portfolio

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start dev server
npm run dev

# 3. Open http://localhost:3000
```

## 📦 Requirements
- Node.js 18+
- npm 9+

## 🛠 Tech Stack
- Next.js 16 + React 19
- TypeScript
- Tailwind CSS v4
- React Three Fiber + Three.js
- Framer Motion

## 🚀 Deploy to Vercel
```bash
npm i -g vercel
vercel
```
