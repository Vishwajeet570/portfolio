## ⚡ Quick Start

### Clone Repository

```bash
git clone <repository-url>
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🚀 Deployment

### Netlify

```bash
npm run build
```

3. Add environment variables
